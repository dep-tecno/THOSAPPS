# THOSLOGO

Fitxers de l'aplicació THOSLOGO.

- Entrada pública: [thoslogo.html](../thoslogo.html).
- Codi complet: [index.html](index.html).
- Imatge de la targeta: [thoslogo.png](thoslogo.png).

La portada conserva l'enllaç públic i utilitza la imatge d'aquesta carpeta. L'entrada pública carrega index.html dins d'un iframe. El codi i la imatge traslladats són idèntics als originals.

Les llibreries i la font mantenen les adreces completes. El logo continua tornant a https://tecno-apps.cat/ i el desat local conserva la clau thoslogo_v1_code.

L'HTML antic de l'arrel s'ha retirat. Per compartir l'app, utilitzeu https://tecno-apps.cat/thoslogo.html.
