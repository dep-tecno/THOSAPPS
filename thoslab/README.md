# THOSLAB

Fitxers de l'aplicació THOSLAB.

- Entrada pública: [thoslab.html](../thoslab.html).
- Codi complet: [index.html](index.html).
- Imatge de la targeta: [thoslab.png](thoslab.png).
- El logo torna a https://tecno-apps.cat/ amb target="_top".

La portada obre l'entrada pública i utilitza la imatge d'aquesta carpeta. L'entrada pública carrega index.html dins d'un iframe.

Els fitxers antics i la imatge duplicada de l'arrel s'han retirat. Per compartir l'app, utilitzeu https://tecno-apps.cat/thoslab.html.

La recuperació local conserva la clau thoslab_autosave. Les millores de càrrega de Babel i Tailwind queden per a un projecte posterior.
