# THOSLAB

Primera app ordenada en una carpeta pròpia.

- Entrada pública: [thoslab.html](../thoslab.html).
- Codi complet: [index.html](index.html).
- Imatge de la targeta: [thoslab.png](thoslab.png).
- La imatge thoslab.png de l'arrel es conserva per als index.html antics en memòria cau.
- El logo torna a https://tecno-apps.cat/ amb target="_top".

La reorganització conserva el codi de l'app byte per byte. No canvia la simulació, Babel, React, Tailwind ni la clau de recuperació local thoslab_autosave.

THOSLAB.html a l'arrel es conserva temporalment com una redirecció al codi nou. Això manté operatius els accessos antics i també els iframes antics guardats a la memòria cau. Com que aquest nom només difereix per majúscules de thoslab.html, la col·lisió a Windows continua pendent mentre es conserva aquesta compatibilitat. Treballar amb un checkout parcial o amb les API de GitHub per aquests dos fitxers.

Abans de retirar l'accés antic, revisar els enllaços compartits fora del repositori. La resta d'apps es reorganitzaran una a una després de revisar aquesta primera prova.
