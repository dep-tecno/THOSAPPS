# THOSMAP

Fitxers de l'aplicació THOSMAP.

- Entrada pública: [thosmap.html](../thosmap.html).
- Codi complet: [index.html](index.html).
- Imatge de la targeta: [thosmap.png](thosmap.png).

La portada conserva l'enllaç públic i utilitza la imatge d'aquesta carpeta. L'entrada pública carrega index.html dins d'un iframe a pantalla completa. El codi i la imatge traslladats són idèntics als originals.

La política de seguretat, les llibreries externes, la càrrega d'imatges com a dades i la clau local thosmap_autosave es mantenen. El logo continua tornant a https://tecno-apps.cat/.

Per compartir l'app, utilitzeu https://tecno-apps.cat/thosmap.html.
