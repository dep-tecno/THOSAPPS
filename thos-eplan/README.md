# THOSePLANT

Aplicació d'edició de plànols d'habitatges i instal·lacions elèctriques.

- Adreça pública: [thos-eplan.html](https://tecno-apps.cat/thos-eplan.html)
- Aplicació: [index.html](index.html)
- Documentació: [THOS-EPLAN.md](THOS-EPLAN.md)

La pàgina `thos-eplan.html` de l'arrel del repositori conserva l'adreça pública i carrega aquesta aplicació. Els scripts, els estils i les imatges utilitzats per THOSePLANT es guarden en aquesta carpeta.
