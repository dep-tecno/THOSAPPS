# THOSDRUINO

Fitxers de l'aplicació THOSDRUINO.

- Entrada pública: [thosdruino.html](../thosdruino.html).
- Codi complet: [index.html](index.html).
- Imatge de la targeta: [thosdruino-card.svg](thosdruino-card.svg).

La portada conserva l'enllaç públic i utilitza l'SVG d'aquesta carpeta. L'entrada pública carrega index.html dins d'un iframe a pantalla completa. El codi i la imatge traslladats són idèntics als originals.

Els dibuixos dels components i les plaques continuen integrats en el codi. El logo torna a https://tecno-apps.cat/ i la recuperació local conserva la clau thosdruino_autosave.

El JPG antic sense referències s'ha retirat. Per compartir l'app, utilitzeu https://tecno-apps.cat/thosdruino.html.
